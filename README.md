# كُنّاش

> دفتر العالِم الذي يجمع فيه ما ينفعه

مكتب عمل شخصي على الماك: يشتغل على مجلد تختاره أنت، وينفّذ مهامك المتكررة بمهارات تكتبها بنفسك، عبر النموذج الذي تربطه.

**الحالة: قيد البناء المبكر — لا يصلح للاستعمال بعد.** ما يعمل اليوم: اختيار مجلد العمل، محادثة متدفقة عبر مزوّد OpenAI-compatible، ومكتبة مهارات وعملاء تُحرَّر من داخل التطبيق. لا حلقة أدوات بعد، فلا يقرأ ملفاتك ولا يكتب فيها.

## التشغيل من المصدر

```bash
npm install
npm start
```

يحتاج Node.js وmacOS. أضف مفتاح مزوّد من ⚙️ الإعدادات لتعمل الدردشة.

## أين تُحفظ الأشياء

| ماذا | أين |
|---|---|
| المفاتيح وآخر مجلد عمل | مجلد بيانات التطبيق على جهازك |
| الجلسات | `<مجلد عملك>/.kunnash/sessions.json` |
| المهارات والعملاء | `<مجلد عملك>/.kunnash/{skills,agents}` (ويقرأ `.claude/` إن وُجدت) |

لا خادم لهذا المشروع، ولا حساب، ولا تتبّع. وما تكتبه في المحادثة يغادر جهازك إلى مزوّد النموذج الذي اخترته — هذا ما يفعله أي تطبيق يستعمل نموذجًا، ونقوله صراحةً.
